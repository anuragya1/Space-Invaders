Technical Architecture

The core is deterministic by design.

01

Fixed Tick Simulation

Game logic advances at a stable tick rate independent of SDL3 rendering.

02

Input Source Abstraction

Keyboard, AI, replay, and co-op feed the same action-mask interface.

03

Replay And Lockstep

Recorded input frames and network co-op use the same synchronization primitive.

04

Renderer Separation

SDL3 observes simulation state for interpolation, particles, shake, and HUD feedback.

FAQ

Common setup questions.

Do I need SDL3?

Only for the windowed SDL3 build. The terminal tools build without external dependencies.

Where are saves stored?

Persistent files are plain text in the working directory, including stats, achievements, saves, and replays.

Can I verify a replay?

Yes. Use the terminal binary with `--verify-replay FILE` to confirm deterministic replay integrity.

How do I contribute?

Start with the contributor guide, run the CMake test flow, and open a focused pull request.
