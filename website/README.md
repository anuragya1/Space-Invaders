# Project Website

This folder contains the static website for Space Invaders - Pro Edition.

Open `website/index.html` directly in a browser. There is no build step and no
package manager.

## Media

The page uses local media under `website/assets/`:

- `assets/video/demo.mp4`
- `assets/screenshots/boss-fight.png`
- `assets/screenshots/director-pressure.png`
- `assets/screenshots/replay-mode.png`
- `assets/screenshots/wave-level-02.png`
- `assets/screenshots/boss-entry.png`
- `assets/screenshots/boss-clean.png`

Keep future screenshots close to 16:9 if possible. The layout expects wide
gameplay captures and will crop them slightly on small screens.

## Tone

The website should sound like a developer explaining the project honestly. Keep
it practical: what the game is, what is interesting about the systems, how to
run it, and where contributors can help.
